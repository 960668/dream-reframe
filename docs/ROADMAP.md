# Roadmap

优先级从上到下。

## v0.2 · 梦境档案

把一次性工具变成可累积的记录。

- [ ] 登录（邮箱或手机号）与用户隔离
- [ ] 云数据库保存每次重构结果
- [ ] 梦境列表页：按时间翻阅，支持搜索情绪词与意象
- [ ] 梦境详情页 + 一键重新生成

## v0.3 · 单镜头重生

- [ ] 单独重生成某个镜头的文案或提示词，不影响其余镜头
- [ ] 风格锚点可手动编辑，编辑后一键同步到所有镜头
- [ ] 镜头顺序调整

## v0.4 · 直出画面

- [ ] 服务端代理文生图接口，密钥不上浏览器
- [ ] 每个镜头生成一张图，拼成可分享的梦境长图卡片
- [ ] 可选接入图生视频，输出 15 秒短片

## v0.5 · 分享与生态

- [ ] 梦境卡片的海报化导出（保留意象与情绪，隐藏敏感原文）
- [ ] 匿名梦境广场（用户自选是否公开）
- [ ] 提示词模板社区：用户可以沉淀并分享自己的风格锚点

## 技术债

- [ ] E2E 测试覆盖核心链路
- [ ] 错误上报（当前只有本地提示）
- [ ] 无障碍：键盘导航与读屏标签补全
