# Roadmap

优先级从上到下。

## v0.2 · 一键出图 ✅（2026-10-13 已发布）

- [x] 接入 OpenAI 兼容的 `/images/generations`，兼容智谱（`data[0].url`）与硅基流动（`images[0].url`）两种响应形状
- [x] 免费出图模型预置：智谱 `cogview-3-flash`、硅基流动 `Kolors`
- [x] 重构完成后自动出图（可关），逐张串行，避开免费模型并发限制
- [x] 单张重新生成（「换一张」），单张失败不中断整批
- [x] 出图约束 `IMAGE_GUARD` 集中在 `prompts.js`，支持 negative_prompt 的接口单独下发
- [x] 本地代理支持 `/api/image` 转发
- [ ] ~~服务端代理文生图接口~~ 实测智谱 / 硅基流动 / 通义 / Kimi 均允许浏览器直连，纯前端方案成立，不再需要服务端

## v0.3 · 梦境档案

把一次性工具变成可累积的记录。

- [ ] 登录（邮箱或手机号）与用户隔离
- [ ] 云数据库保存每次重构结果（含已生成的图片）
- [ ] 梦境列表页：按时间翻阅，支持搜索情绪词与意象
- [ ] 梦境详情页 + 一键重新生成

## v0.4 · 单画面重生（文案侧）

- [ ] 单独重生成某个画面的文案或提示词，不影响其余画面
- [ ] 风格锚点可手动编辑，编辑后一键同步到所有画面并重出图
- [ ] 画面顺序调整

## v0.4.5 · 梦境感评测集

当前「更像梦了」只能靠肉眼判断，改动提示词后无法回答「到底变好还是变坏」。需要把它变成可测量的。

- [ ] 收集 30-50 段真实梦境口述作为固定评测集
- [ ] 定义可判定的指标：是否出现场景无过渡跳接、是否保留物理不成立、是否有多余的解释性语言、是否有强行收尾
- [ ] 每次改提示词后跑一遍，人工打分记录，形成可回溯的版本对比

这件事优先级不低：提示词是本项目的核心资产，没有评测就等于在盲改。
